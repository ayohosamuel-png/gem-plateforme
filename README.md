# 🎓 IMHOTEP MÉMOIRES

> Plateforme intelligente de gestion électronique, d'analyse par Intelligence Artificielle et de valorisation des mémoires académiques.

## Stack Technique Cloudflare
- **Frontend**: React 19, TypeScript, Tailwind CSS, Vite, Lucide Icons, Motion
- **Backend / Workers**: Cloudflare Pages Functions & Workers API (TypeScript)
- **Base de données**: Cloudflare D1 (SQLite SQL Relationnel)
- **Stockage de Fichiers**: Cloudflare R2 (Stockage PDF sans frais d'egress)
- **Intelligence Artificielle**: Google Gemini API & Cloudflare AI

## Fonctionnalités Clés
1. **🔐 Authentification Multi-Rôles**: Déposant (Étudiant), Encadreur (Enseignant), Visiteur (Public) et Administrateur.
2. **🤖 Vérification de Thèmes IA**: Analyse préventive de la problématique, score de similitude et suggestions académiques.
3. **📝 Analyse Anti-Plagiat IA**: Détection approfondie des citations, paraphrases et génération automatique du rapport PDF.
4. **🧠 Assistant Académique IA**: Copilote intelligent pour formulation de sujets, problématiques, méthodologies et plans de rédaction.
5. **💳 Paiements Intégrés**: MTN Mobile Money, Moov Money, Celtis Cash & Cartes Visa avec déblocage sécurisé des mémoires.
6. **🏷️ Certificats Numériques Authentifiés**: QR Code unique et vérification d'authenticité publique.
7. **📊 Tableaux de Bord Rôles**: Espaces dédiés pour le suivi des dépôts, la validation encadreur et la supervision administrative avec audit logs.
